# Phase 6 — Tips ❌

## Goal
Browsable IELTS improvement tips, filterable by skill and band target.

## Depends On
- BE Phase 6 (tips endpoints)

## Pages
```
/tips    → TipsPage
```

## Feature Structure
```
src/features/tips/
  components/
    TipCard.tsx       # individual tip: skill badge, title, content, band range tag
    TipFilter.tsx     # filter bar: skill tabs + band range selector
    TipList.tsx       # grid of TipCard
  hooks/
    useTips.ts        # fetch tips with filter params
```

## Filter UI
- Skill tabs: All | Reading | Writing | Listening | Speaking | General
- Band range: All | 5-6 | 7+ (radio/toggle)

## Data Fetched
```
GET /api/v1/tips?skill=reading&band_range=7+
```

## TipCard Design
```
┌────────────────────────────┐
│ [Reading]           [7+]   │
│ Title of the tip           │
│ Content preview (2 lines)  │
│ Read more ↓                │
└────────────────────────────┘
```
