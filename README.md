# iVelox — Frontend

React + Vite + TypeScript frontend for iVelox, an IELTS learning and practice platform.

## Tech Stack
- React 18 + Vite + TypeScript
- TanStack Query v5
- Zustand
- Tailwind CSS + shadcn/ui
- Supabase Auth

## Getting Started
```bash
npm install
cp .env.example .env.local  # fill in your Supabase keys
npm run dev
```
